A Team Fortress 2 overhaul mod

M4D Heavy TF2

Every class reworked around one idea: mark a target and the whole team gets a way to punish it. Afterburn that stacks, a Pyro who can heal, an Engineer with a pet drone. Runs alongside your normal TF2 — it changes nothing about your real install.

Download 13 MB · .zip · Windows 64-bit

Windows 64-bit only. Needs TF2 and Source SDK Base 2013 Multiplayer.

You’ll need

Both are free, and both have to be installed in Steam before the mod will start. Steam also needs to be running when you launch it.

Required

Team Fortress 2

The mod reads TF2’s maps, models and sounds straight out of your install. If you’ve never launched TF2 on this machine, do that once first.

Required

Source SDK Base 2013 Multiplayer

This is the engine the mod actually runs on. In Steam, open your Library, click the filter dropdown at the top, tick Tools, then find it in the list and install it.

Install

  1. Unzip it to C:\Games\M4DHeavyTF2\. Make that folder if you don’t have one. The mod writes settings, screenshots and demos next to itself, so it needs somewhere you own. Avoid your Desktop or Documents — on most Windows 11 machines those sync to OneDrive, which locks files mid-write. Avoid Program Files, where Windows blocks writes. And keep it out of your Steam folders, which get cleaned up by “verify integrity”.
  2. Run mod_tf_win64.exe. Windows may warn you about an unknown publisher. That’s expected for an unsigned mod build.
  3. Enjoy. Everything lives in your normal TF2 loadout. Nothing else to set up.
  4. Talk about it. Talk about it on the forums. Talk about it everywhere. Spread the word.

Play together

There are no public servers — one of you hosts, the other connects. Hit ~ to open the console. If nothing happens, turn it on under Options → Keyboard → Advanced → Enable Developer Console.

You host

Start a map, then find your IP and send it over.

> map ctf_2fort
> status

status prints your address. On most home connections you’ll also need to forward UDP 27015 on your router, or use something like Hamachi or ZeroTier to skip that entirely.

You join

Once they’ve given you the address:

> connect 203.0.113.7

Swap in whatever IP they sent you. Same version on both machines or it won’t connect — grab the download from this page rather than passing files around.

If something breaks

It closes instantly, or won’t launch at all.
Steam isn’t running, or Source SDK Base 2013 Multiplayer isn’t installed. Both are required. Launch the SDK Base once from Steam, then try the mod again.
Everything is pink and black checkerboards.
Team Fortress 2 isn’t installed, or has never been run on this machine. Start TF2 normally once so Steam finishes unpacking it, then relaunch the mod.
An engine error about a missing .dll.
Same fix — run Source SDK Base 2013 Multiplayer once from your Steam library first. It installs the engine binaries the mod loads.
We can’t connect to each other.
Check you’re both on this exact build. After that it’s almost always the router — forward UDP 27015 on the host’s side, or put both machines on a Hamachi or ZeroTier network and connect to the address it gives you.
