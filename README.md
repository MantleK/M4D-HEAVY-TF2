# M4D Heavy TF2

A Team Fortress 2 overhaul mod, built on Source SDK Base 2013.

**Download and install: https://mantlek.github.io/M4D-HEAVY-TF2/**
**Discord: https://discord.gg/3ZBDm5Avc**

## What you need

- Team Fortress 2 (free)
- Source SDK Base 2013 Multiplayer (free — in Steam, filter your Library by "Tools")
- Windows 64-bit, with Steam running

Unzip to `C:\Games\M4DHeavyTF2\` and run `M4DHeavyTF2_win64.exe`.
Keep the .exe and the folder next to each other — the launcher works out which game
folder to load from its own filename.
